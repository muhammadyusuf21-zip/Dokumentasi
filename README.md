# 📄 Dokumentasi Perancangan Aplikasi E-Commerce PetShop

## Deskripsi

Repository ini berisi seluruh dokumen yang digunakan dalam proses **perancangan aplikasi E-Commerce PetShop**. Dokumentasi disusun berdasarkan tahapan **Software Development Life Cycle (SDLC)** sebagai bagian dari tugas mata kuliah **Perancangan Perangkat Lunak**.

Seluruh dokumen dalam repository ini digunakan sebagai acuan sebelum proses implementasi sistem dilakukan.

---

## Tujuan Repository

Repository ini dibuat untuk:

* Menyimpan seluruh dokumentasi proyek secara terpusat.
* Memudahkan kolaborasi antaranggota kelompok.
* Mendokumentasikan setiap tahapan SDLC.
* Menyimpan riwayat perubahan (versioning) menggunakan Git dan GitHub.

## Model Pengembangan

Model SDLC yang digunakan dalam proyek ini adalah **Waterfall**, yang terdiri dari tahapan:

1. Planning
2. Requirement Analysis
3. System Design
4. Implementation 
5. Testing
6. Deployment
7. Maintenance
