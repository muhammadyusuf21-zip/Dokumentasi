# 📄 Dokumentasi Perancangan Aplikasi E-Commerce PetShop

## Deskripsi

Repository ini berisi seluruh dokumen yang digunakan dalam proses **perancangan aplikasi E-Commerce PetShop**. Dokumentasi disusun berdasarkan tahapan **Software Development Life Cycle (SDLC)** sebagai bagian dari tugas mata kuliah **Perancangan Perangkat Lunak**.
